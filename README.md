# 🚀 VIBE.DEV | The Vibe Coding Era

> "우리는 문법을 외우지 않는다. 우리는 흐름을 타고, AI와 듀엣으로 세계를 창조한다."

바이브 코딩의 시작을 알리는 인터랙티브 **HELLO WORLD** 프로젝트입니다.

---

## ✨ Features

- 🌌 **Cyber Neon & Glassmorphism UI**: 4가지 네온 테마 전환 (`V` 키 또는 상단 버튼)
- 🎨 **HTML5 Canvas Starfield**: 동적 인터랙티브 코드/스타 파티클 백그라운드
- 🎹 **Web Audio API Synth Engine**: 앰비언트 Lo-Fi 사이버 드론 BGM & 사운드 FX (`M` 키)
- 💻 **Vibe Generator Console**: 프롬프트 시뮬레이션 및 실시간 AI 코딩 콘솔
- ⚡ **Flow Meter & Confetti Party**: 스페이스바(`Space`) 및 클릭 인터랙션으로 폭죽 효과
- 📜 **Vibe Coder's Creed**: 바이브 코더들을 위한 영감과 확언 생성기

---

## 🚀 Getting Started

별도의 설치 과정 없이 브라우저에서 `hello.html`을 바로 실행하세요.

```bash
# 브라우저로 열기
start hello.html
```

---

## ⌨️ Shortcuts

- <kbd>Space</kbd> : 축하 폭죽(Confetti) 발사
- <kbd>V</kbd> : 테마 변경 (Neon / Matrix / Sunset / Quantum)
- <kbd>M</kbd> : 사운드 온/오프
