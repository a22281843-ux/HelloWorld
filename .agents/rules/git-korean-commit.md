# Git Commit Message & Auto-Commit Guidelines

1. **한글 커밋 메시지**: 모든 Git 커밋 메시지는 반드시 **한글**로 작성합니다.
2. **오토커밋(Auto-Commit)**: 코드나 문서의 변경사항이 발생하면 요청이 끝날 때 자동으로 Git에 스테이징 및 커밋을 수행합니다.

## 커밋 메시지 형식
`<유형>: <설명>`

### 유형(Type) 예시
- **기능**: 새로운 기능 추가
- **수정**: 버그 또는 오류 수정
- **디자인**: UI/UX 스타일 및 디자인 요소 변경
- **문서**: README, 문서 등의 추가/수정
- **설정**: 환경설정, 규칙 변경
- **리팩토링**: 코드 구조 개선 (기능 변화 없음)
