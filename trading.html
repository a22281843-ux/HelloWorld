종목 사양

값 확인하는 법 (꼭 확인하세요)

"1.0 가격 변동 시 1랏 손익"은 가격이 1.00 움직일 때 1랏의 손익($)입니다.

  • MT5 → 시세창에서 종목 길게 누르기(우클릭) → 사양(Specification) → 계약 크기(Contract size) 확인
  • 골드(XAUUSD): 보통 계약 크기 100oz → 1.00 변동 = $100/랏
  • 나스닥(NAS100 / USTEC): 브로커마다 계약 크기가 1, 10 등으로 다릅니다 → 계약 크기 × 1 = $/랏
  • 최소 랏·랏 단위도 사양의 최소 거래량 / 거래량 단계와 똑같이 맞추세요.
  • 수수료는 랏당 왕복(진입+청산) 금액입니다. 없으면 0.

가장 확실한 검증: 데모에서 0.01랏 주문 → 가격 1.00 움직였을 때 손익 × 100 = 이 값.

MT5 연동 (반자동)

처음 설정하는 법 (한 번만)
  • MT5 데스크톱 → 파일 → 데이터 폴더 열기 → MQL5\Experts 폴더에 TradeDeskExport.mq5 복사
  • MT5 왼쪽 내비게이터 → Expert Advisors에서 우클릭 → 새로고침 (안 보이면 파일을 더블클릭해 MetaEditor에서 컴파일(F7))
  • TradeDeskExport를 아무 차트에 끌어다 놓기 → 확인. 주문은 넣지 않으므로 알고리즘 트레이딩을 켤 필요 없음
  • MT5 하단 전문가(Experts) 탭에 "TradeDesk: N개 포지션을 저장했습니다"가 보이면 성공
  • MT5 전문가(Experts) 탭의 "파일 위치 →" 줄을 우클릭 → 복사해서 경로를 확인
  • 여기서 MT5 동기화 → 파일 선택 창 아래 파일 이름 칸에 그 경로를 붙여넣고 Enter. 다음부터는 브라우저가 그 폴더를 기억해서 파일만 더블클릭하면 됩니다
  • 또는 MT5 파일 → 데이터 폴더 열기 → MQL5 → Files에서 TradeDesk_history.csv를 이 페이지 위로 끌어다 놓아도 동기화됩니다

핸드폰 MT5로 한 매매도 같은 계좌면 노트북 MT5가 켜질 때 함께 저장됩니다. 가격·랏·손익·시각은 MT5 값으로 채워지고, 셋업·시간봉·감정·메모는 직접 입력한 내용이 유지됩니다.
