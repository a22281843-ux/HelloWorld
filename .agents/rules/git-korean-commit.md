# Git Commit Message Guidelines

모든 Git 커밋 메시지는 반드시 **한글**로 작성합니다.

## 커밋 메시지 형식
`<유형>: <설명>`

### 유형(Type) 예시
- **기능**: 새로운 기능 추가
- **수정**: 버그 또는 오류 수정
- **디자인**: UI/UX 스타일 및 디자인 요소 변경
- **문서**: README, 문서 등의 추가/수정
- **리팩토링**: 코드 구조 개선 (기능 변화 없음)
- **성능**: 성능 향상 관련 수정
- **빌드**: 빌드 설정, 의존성 패키지 관리
- **테스트**: 테스트 코드 추가 또는 수정
